# Contributing

本仓库采用“证据先于叙事”的维护方式。

## 提交新事实

1. 将来源登记到 `sources.csv`；
2. 新建或更新来源卡；
3. 在 Evidence Ledger 中增加原子主张；
4. 标明支持、反证、冲突和限制；
5. 更新受影响的长期阅读文档；
6. 执行 `scripts/audit/verify_repository.ps1`。

## 不接受的变更

- 只依据搜索摘要或二手榜单修改关键结论；
- 把不同组件、版本或许可证互相借证；
- 将供应商自报升级为客户第一方生产采用；
- 通过总分、排名或“最强”等措辞制造伪精确性；
- 覆盖历史文件而不保留版本与变更理由。
