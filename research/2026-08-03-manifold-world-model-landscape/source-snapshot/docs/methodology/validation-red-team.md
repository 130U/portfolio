# 验证与 Red Team

## 验证对象

验证不仅覆盖技术能力，还覆盖：

- 法律实体和地域；
- 模型与组件版本；
- API、账户和访问方式；
- 定价、SLA 和撤销权；
- 数据训练权和再分发；
- 独立复现；
- 客户、伙伴和供应商采用证据的归属。

## 三条 Red Team 线

### 技术、来源和版本

检查动作是否真的条件化未来、版本是否漂移、评测是否可比、不同组件是否互借能力。

### 商业、访问和许可

检查“公开”“商用”“客户”“部署”等词是否越过来源上限，许可证是否覆盖完整依赖链。

### 范围、叙事和治理

检查 Gate 结论是否条件化、固定五席是否漂移、观察对象是否被写成正式候选、状态文件和审批边界是否一致。

## 典型纠正

- Cosmos3-Generator 产品版本修正为 Release 1.0.0；
- Generator NIM 的 T2V/I2V 不能借给 action runtime；
- Runway Worlds 与 Robotics 分栏；
- World Labs RTFM 与 World API 分立；
- Odyssey 150 秒、60 分钟和 15 分钟解释为当前默认运营限制，不是 SLA；
- 供应商托管 PoC、伙伴自报部署和独立产品体验不得升级为客户付费生产采用。

## Content Lock 后的验证

Content Lock 冻结四份文件及 SHA256。Storyboard 和 PPT 只能改变布局与视觉，不得修改锁定事实；若需要改变事实，应重新审批 Content Lock。
