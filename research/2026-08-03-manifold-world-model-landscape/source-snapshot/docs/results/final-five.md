# 固定五席

## World Labs

**已成立：** RTFM 展示位姿条件未来和空间记忆；分立的 Marble / World API 提供公开计价。  
**未成立：** 持久动态物体、独立系统复现、客户第一方付费生产采用。  
**意义：** 空间世界接口可能绕行专有生成和交付环节。  
**触发器：** RTFM 动态交互获得独立复现，或 World API 推出版本化动态交互服务。

## Odyssey

**已成立：** 历史状态和动作条件未来；官方文档给出 API key、JS/Python 接入和连接规则。  
**未成立：** 实际账户和持续调用未独立确认；运营时限不是 SLA。  
**意义：** 若可靠性和单位经济性闭合，可能形成实时世界流基础设施。  
**触发器：** 独立账户在公开价格和 SLA 下完成长期稳定调用。

## Runway

**已成立：** Worlds 有公开申请制 early access；Robotics 描述动作条件 rollout 和多种部署洽谈路径。  
**未成立：** 两条路线均缺公开价格、SLA、独立复现和伙伴侧生产确认。  
**意义：** 内容平台可能向可探索世界延伸，Robotics 只构成相邻压力。  
**触发器：** 任一组件获得独立调用和伙伴侧生产确认。

## Decart

**已成立：** 公开账户、0.02 美元/秒、有状态驾驶动作和三向后续视图。  
**未成立：** 正式商用、连续性保证、客户付费生产采用；独立体验发现漂移、记忆和碰撞问题。  
**意义：** 世界模型竞争进入计量计费的具体任务。  
**触发器：** Preview 进入正式商用并闭合 SLA、数据和责任边界。

## NVIDIA Cosmos 3

**已成立：** 动作条件前向动力学有可运行材料和自托管路径。  
**未成立：** 稳定 action runtime/action NIM、完整依赖许可、TCO、独立复现和客户第一方采用。  
**组件边界：** Cosmos3-Generator NIM Release 1.0.0 只列 T2V/I2V，不代表 action mode。  
**意义：** 自托管组件既可能绕行专有供应商，也可能成为共同底层。  
**触发器：** 稳定动作运行时或 action NIM 正式发布并获得独立复现。
