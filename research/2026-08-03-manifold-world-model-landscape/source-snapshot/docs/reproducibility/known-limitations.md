# 已知限制

## 1. 截止日期限制

产品、许可、价格、API、模型版本和采用状态可能在 2026-07-14 后变化。任何更新都应重新打开原始来源。

## 2. 原始页面快照

来源卡记录研究日的支持内容和限制，但并非所有网页都保存了完整 HTML/PDF 快照。若页面变化，复现可能依赖版本仓库、官方 Markdown 或第三方归档。

## 3. Manifold 内部未知

项目没有 Manifold 的实际客户、标准交付单元、商业阶段、合同和未来路线，因此竞争关系只能是条件性推断。

## 4. Agent provenance

仓库能追踪任务级 Agent，但不能为每条 Claim 完整还原最初发现它的子 Agent。后续应增加 Claim→Agent 字段。

## 5. 隐藏思维链

仓库不发布模型隐藏的逐 token 思维链。可审计理由通过 Storyline、决策表、反证、来源和状态迁移表达。

## 6. PPT 与 PDF

PPTX v1.4 可验证但生成器仍需参数化。PDF 未启动、未生成，不应把任何文件称为最终 PDF。

## 7. 第三方权利

来源内容、代码、论文、商标和产品资料继续受各自许可约束。完整归档不等于获得公开再分发第三方内容的权利，因此仓库初始设置为私有。
