# 最终结论

## 市场层结论

海外世界模型已经出现三种交付路径：公开计价接口、申请制/受控入口、可下载/自托管组件。竞争单元正在从单一模型效果扩大到接口、运行时、部署、集成、数据权和总体拥有成本。

## 证据上限

五席当前最高证据包括：

- 供应商托管原型或工作流演示；
- 公司或伙伴自报测试和集成；
- 公开计价的供应路径；
- 可下载、自托管的模型材料。

尚未恢复到客户第一方确认的付费生产部署、续约或收入证据。

## 固定五席的研究价值

| 对象 | 代表路径 | 主要限制 |
|---|---|---|
| World Labs | 空间世界产品/API＋实时导航研究 | RTFM 与 World API 分立；动态交互和客户采用未闭合 |
| Odyssey | 实时 world-stream developer service | 实际账户、稳定性和 SLA 未独立确认 |
| Runway | 内容平台向 Worlds/Robotics 双分支迁移 | 两组件不能互借；访问、复现和伙伴部署未闭合 |
| Decart | 按秒计费的 driving-first Preview API | 动作域窄；Beta、数据权、漂移和碰撞问题 |
| NVIDIA Cosmos 3 | 可下载、自托管的动作条件组件平台 | 稳定 action runtime/action NIM、TCO 和客户采用未闭合 |

## 对 Manifold 的结论

公开信息不足以确认 Manifold 已经与这些对象争夺相同客户、预算或采购位置。更稳健的做法是先定义自身标准交付单元、建立共同验证资产，并锁定数据和部署权利边界，再用可审计事件触发竞争关系重审。
